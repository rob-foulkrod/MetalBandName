# GitHub Advanced Security Labs

## Lab 1: Remove commit history

[GitHub Skills: Change commit history](https://github.com/skills/change-commit-history)

Accidental commits can be tricky to remove with Git. In this GitHub Skills
course, you'll use BFG Repo-Cleaner to change the history of a Git repository.
You can apply what you learn in this course to fully remove sensitive material
from your own repository.

- **Learning Path:** GitHub Advanced Security Part 1 of 2
- **Lab URL:** <https://github.com/skills/change-commit-history>
